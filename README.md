# NANDO Messenger — Web prototype

واجهة مراسلة عربية متجاوبة مستوحاة من تطبيقات المحادثة، تعمل على الهاتف والكمبيوتر.

## التشغيل
افتح `index.html` في متصفح أو انشر محتويات هذا الفرع عبر GitHub Pages.

## الحالة الحالية
- قائمة محادثات تجريبية، بحث وفلاتر.
- فتح محادثة وإرسال رسائل داخل واجهة المتصفح.
- اختيار ملف لعرض مرفق تجريبي.
- تصميم متجاوب مع شاشات iPhone.

**مهم:** هذه نسخة واجهة أمامية فقط. لا يوجد تسجيل دخول حقيقي أو إرسال رسائل بين مستخدمين أو تخزين سحابي/خلفية بعد. يلزم بناء API وقاعدة بيانات ومصادقة وإشعارات قبل إطلاق خدمة مراسلة حقيقية.

هذا المشروع مستقل، وليس نسخة رسمية من Telegram ولا يتضمن شيفرته أو علامته التجارية.
