# NANDO TAP

لعبة نقر عربية مستوحاة من ألعاب tap-to-earn، بهوية ورسومات أصلية بسيطة.

## الحالة الحالية
- واجهة عربية متجاوبة للهواتف.
- جمع عملات بالنقر.
- طاقة تتجدد تلقائياً.
- ترقية لقوة النقر.
- حفظ محلي للتقدم عبر المتصفح (localStorage).

## التشغيل
افتح `index.html` في متصفح، أو انشر ملفات المستودع على استضافة صفحات ثابتة.

## ملاحظات مهمة
هذه نسخة أولية للواجهة واللعب المحلي فقط. الرصيد محفوظ على جهاز اللاعب، وليس قاعدة بيانات مركزية، لذلك لا تعتبر العملات أو الترتيب موثوقاً ولا توجد حماية من التلاعب بعد. قبل إطلاق لعبة عامة نحتاج خادماً وPostgreSQL والتحقق من هوية Telegram على الخادم، مع إضافة المهام والإحالات ولوحة المتصدرين.

هذا المشروع مستقل، ولا يتضمن الشعار أو الرسومات أو الشيفرة الخاصة باللعبة الرسمية Hamster Kombat.
